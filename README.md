# ☕ Coffee Shop

A modern and responsive coffee shop website built with **HTML, CSS, and JavaScript**.

The website presents a coffee shop with a warm, elegant design, coffee menu, information about the shop, and contact section.

## ✨ Features

* 🏠 Home section with hero banner
* ☕ Coffee menu with prices
* 📖 About Us section
* 📞 Contact information
* 📝 Contact form
* 📱 Responsive design for mobile devices
* 🎨 Smooth scrolling and hover animations
* ⭐ Font Awesome icons
* ✍️ Google Fonts — Playfair Display

## 🛠️ Technologies

* **HTML5**
* **CSS3**
* **JavaScript**
* **Font Awesome**
* **Google Fonts**

## 🚀 Getting Started

No installation is required.

1. Clone the repository:

```bash
git clone https://github.com/armen-marg/coffee-shop.git
```

2. Open the project folder:

```bash
cd coffee-shop
```

3. Open `index.html` in your browser.

## 📱 Responsive Design

The website adapts to different screen sizes using CSS media queries and works on:

* 💻 Desktop
* 📱 Mobile
* 📟 Tablet
